# OSINT-REILLY v5

Легальна розвідка з відкритих джерел і аналітика за заданими темами:
новини, ринки (акції, індекси, сировина, валюти, крипта), макроекономіка,
медійна увага, моніторинг сторінок, перевірка гіпотез і журнал прогнозів
з оцінкою точності.

Інтерфейс: вікно на Python (tkinter, входить у стандартний Python) або консоль;
мови — en, uk, de, fr, es, it, pl. Мова задається у вікні (список «Мова»,
запам'ятовується), у `.env` (`REILLY_LANG`) або разово `--lang de`.

Списки джерел і профілів — звичайні JSON-файли, їх можна правити:

* `sources.json` — RSS-стрічки: назва, адреса, мова, рівень довіри (`tier` 1–3), теги профілів,
  `enabled: false` вимикає стрічку;
* `profiles.json` — запити по мовах, ключові слова, активи, країни, додаткові дані, а також
  `locations` — міста й точки на річках для попереджень про лиха (зараз Польща і Україна).

Чесно про прогноз лих: погода, повені, якість повітря і магнітні бурі прогнозуються на
1–10 днів за моделями; землетруси не прогнозує ніхто — показується лише поточна активність.

## Встановлення (Windows)

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env
```

Ключі в `.env` не обов'язкові: без них працюють усі безкоштовні джерела.
`.env` прописаний у `.gitignore` і на GitHub не потрапляє.

## Запуск

Найкоротше: `reilly.bat` (подвійний клік — вікно; `reilly.bat profile war_ua` — консоль).
Щоб запускати командою `reilly` з будь-якої теки PowerShell, додайте в `$PROFILE`:
`function reilly { & "<шлях до проєкту>\reilly.bat" @args }`.

```bash
.venv\Scripts\python main.py
```
Вікно, ліворуч три вкладки:

* **Профілі** — позначити й «Запустити вибрані» (або «Запустити всі» вгорі);
* **Завдання** — описати своїми словами, що треба з'ясувати; агент сам добирає джерела
  і дані з каталогу, шукає новини, перевіряє прогалини, дошукує і пише аналіз
  (відповідь, факти з джерелами, сценарії з імовірностями, сигнали для стеження).
  Кроки агента видно окремим розділом звіту. Без ключа ШІ агент лише добирає профілі
  за словами завдання;
* **Своя тема** — ручне налаштування запиту, активів, країн і гіпотези.

Праворуч — вкладка на кожен запуск, у ній розділи звіту таблицями (подвійний клік
відкриває джерело), «Копіювати для ШІ» — звіт із готовим запитом для будь-якого чату.
Унизу — журнал подій. Угорі — «Журнал прогнозів», «Тека звітів», «⚙ Налаштування»:

* **Загальні** — мова, ключ і модель OpenRouter (зберігаються в `.env`), контактний e-mail;
* **Джерела** — усі RSS-стрічки: увімкнути / вимкнути, перевірити, видалити; додати нове
  джерело за адресою сайту (стрічку RSS програма знайде сама), вибрати мову, рівень
  довіри і профілі, де його використовувати.

```bash
.venv\Scripts\python main.py task "Чи зросте ризик відключень світла в Україні цієї зими?"
```
Те саме завдання для агента з консолі.

```bash
.venv\Scripts\python main.py profile war_ua hazards
```
Профілі в консолі (без назв — усі): `war_ua eu_poland ua_politics economy crypto science_tech hazards`.

```bash
.venv\Scripts\python main.py console
```
Консольне меню (нова тема, файл тем, журнал прогнозів, мова).

```bash
.venv\Scripts\python main.py --lang uk run "Енергетична система України" --langs uk,en --countries UA --assets MTF=F --hypothesis "Графіки відключень розширять" --asset-direction up --prior 0.4
```

```bash
.venv\Scripts\python main.py topics topics.example.json
```

```bash
.venv\Scripts\python main.py journal
```

```bash
.venv\Scripts\python main.py resolve <id> yes
```

Параметри `run`:

| Параметр | Зміст |
|---|---|
| `--langs en,de,pl` | мови пошуку (LLM перекладає запит на кожну) |
| `--assets BTC,GC=F,^GDAXI,AAPL` | активи; без параметра визначаються з теми (bitcoin, gold, brent, dax…) |
| `--countries DE,PL` | макродані World Bank; без параметра визначаються з теми |
| `--urls https://…` | публічні сторінки для моніторингу змін (robots.txt дотримується) |
| `--hypothesis "…" --polarity risk/positive --prior 0.3` | байєсівська перевірка гіпотези |
| `--asset-direction up/down` | який рух активів підтверджує гіпотезу (стрибок ціни газу = risk + up) |
| `--horizon 30` | горизонт прогнозу, днів |
| `--no-llm`, `--no-journal` | без LLM / без запису прогнозів |

Звіти: `state/reports/*.json|md|html`. Журнал: `state/forecasts.jsonl`.

## Аналітика

| Блок | Методи |
|---|---|
| Повні тексти | для 8 головних сюжетів читаються статті двох різних видань (robots.txt дотримується, платні й закриті сторінки не обходяться); ШІ витягує конкретні твердження (хто, що, коли, скільки) і суперечності між виданнями; без ШІ — речення з числами й датами. Вимикається прапорцем «Читати повні статті» або `--no-read` |
| Паспорт сигналу (5 факторів) | R релевантність, A = 1/(1+днів·S), V значущість джерела, Snt тональність, T істинність ±1/±2 через підтвердження незалежними джерелами |
| Методи REILLY | індекс обмежень Ґолдратта, лінгвістичний стрес, інверсія капіталу, частка неперевірених тверджень, Джервіс (слова проти грошей) — багатомовні лексикони |
| Ринки | дохідність, волатильність, Шарп, max drawdown, VaR/CVaR 95%, RSI, MACD, Bollinger, SMA 50/200, показник Херста, марковські режими, Монте-Карло (блочний бутстреп) → P(зростання), діапазон 90%, кореляції |
| Ряди уваги / новин | робастний z-score (медіана/MAD), аномалії, тренд, марковський ланцюг CALM/ELEVATED/CRISIS проти базової частоти |
| Макро | останнє значення, середнє за 5 р., тренд, Holt із затуханням тренду |
| Логіка | байєсівське оновлення гіпотези: кожен доказ дає log-likelihood ratio, усі внески видно у звіті |
| Лиха | пороги рівнів «увага / попередження / небезпека» для спеки, морозу, вітру, опадів, пожежної небезпеки; витрата річки проти медіани 60 днів; індекс EAQI; Kp |
| Журнал прогнозів | кожна ймовірність записується; ринкові закриваються автоматично за ціною, гіпотези — `resolve`; Brier score і влучність |

Ймовірності — модельні оцінки, а не гарантія чи інвестиційна порада.
Ваги доказів свідомо помірні; реальну якість показує Brier score у журналі.
